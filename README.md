# Session Spark Learning

Role: You are an expert educational web designer and full-stack developer.

Goal: Create a responsive website for the ESSEC Digital Platforms course assignment titled "ESSEC Digital Platforms - Guest Speaker Hub". The site must contain a tab for each guest speaker session this semester, with each tab containing an interactive game to consolidate what was learned in that session.

Target audience: Master students in Digital Platforms with little to no coding experience.

Core pages and tabs required:
1. Main Navigation Layout: Top navigation bar titled "ESSEC MMD - Digital Platforms Hub" with tabs for guest speaker sessions.
2. Tab 1 (Active): "Session 1: LaunchLab Vibe Coding" - containing a simple interactive concept match quiz strictly testing the key slide definitions.
3. Placeholder Tabs (Disabled / Coming Soon): "Session 2: Guest Speaker", "Session 3: Guest Speaker", "Session 4: Guest Speaker" (built so it can be easily expanded with more session tabs later).

Design style:
1. Modern, clean, and approachable
2. Light background, bold headings
3. Friendly typography (not corporate)

Key features:
1. Clean, student-friendly UI
2. Easy navigation between session tabs
3. Interactive quiz game on Tab 1 with instant visual feedback (green/red) and score summary
4. Mobile-first design
5. Pure client-side logic (no login or backend database)

Content for Tab 1 Interactive Game (Strict Slide Terms):
- 5 Multiple-Choice Questions strictly matching slide definitions:
  Q1: According to the slides, what is index.html?
      - Correct: The words, structure, every heading, button and paragraph people actually read.
  Q2: What is styles.css used for?
      - Correct: The look: colours, fonts, spacing, and how it changes on a phone versus a laptop.
  Q3: What does script.js control?
      - Correct: The behaviour: what happens when somebody clicks, types, or hits submit.
  Q4: What is a GitHub Repository?
      - Correct: The single location where all project files and their history are kept.
  Q5: What is the main function of Vercel?
      - Correct: Reads your GitHub repo, builds the site, and hosts it at a live public link.
